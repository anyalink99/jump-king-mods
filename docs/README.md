# Find a guide

For installation, controls and settings, start with the
[mod catalog](../mods/README.md) and the chosen mod's README.

## Make a map

- [Worldsmith Extension](../worldsmith-extension/README.md): install and use the editor extension.
- [Mapping handbook](../mods/mega-mapping-expansion/docs/authoring.md): add a first scene.
- [Mapping guides](../mods/mega-mapping-expansion/docs/index.md): teleports, behavior trees, narrative and effects.
- [Multiplayer Debug tests](../mods/multiplayer-expansion/docs/debug-testing.md): test a map with two clients.
- [Block registry](modding/block-registry/README.md): find reserved collision colours.

## Write or maintain a mod

- [First Runtime mod](../mods/jk-runtime/docs/getting-started.md): build the working template.
- [Runtime handbook](../mods/jk-runtime/docs/index.md): lifecycle, input, UI and shared world services.
- [Builds and tests](testing.md): select checks and understand their limits.
- [Local files](local-files.md): find packages, caches and scratch output.
- [Worldsmith development](../worldsmith-extension/docs/development.md): extension internals and builds.
- [Credits](../CREDITS.md): authors and third-party notices.
