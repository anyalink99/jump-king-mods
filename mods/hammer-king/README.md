# Hammer King (retired standalone package)

Hammer is equipment in [More Items](../more-items/README.md). Its complete
implementation, assets and regression tests live there. Buy it for three silver
coins or use `Add Hammer` in `ModsDebugActions`, then equip it in Inventory.

Do not install `HammerKing.dll` alongside More Items 2.1+. The More Items
installer backs up and removes that obsolete DLL. Existing standalone settings
and backups are retained; the default 100% uses the former 120% force.

The old build command forwards to More Items for compatibility and does not
produce a standalone Hammer package. See [physics and checks](../more-items/docs/hammer.md).
