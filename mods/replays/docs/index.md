# Replays guides

Start with [saving and watching](../README.md#saving-and-watching) to record a run,
open the library or race a ghost. [Settings and files](../README.md#settings-and-files)
lists the three menu switches and the recording directory.

| Task | Guide |
| --- | --- |
| Understand capture, seek, sound and world state | [Recording and playback](recording.md) |
| Check old-format support or timing | [Format](recording.md#format) |
| Integrate completion reports | [Completion bridge](integration.md) |
| Build the package | [Build](../README.md#build) |

Playback owns the live world temporarily; a race ghost doesn't. The format guide
explains that distinction and what happens when state capture exceeds a limit.
Release history is in the [changelog](../CHANGELOG.md).
