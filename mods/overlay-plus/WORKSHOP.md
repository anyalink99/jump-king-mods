# Overlay+

Arrange the native timer, Area splits, keyboard/gamepad controls and text anywhere in your
game window, including fullscreen black bars. Press F10 on a loaded map or choose
Edit Overlay+ in the pause menu. Drag, resize, group and style widgets directly
over the scene, with Jump King's own frames and fonts. No external editor.

The native Overlay+ settings menu includes Enable (on by default). Switch it off
to stop tracking and release all Overlay resources and hooks. Hide HUD in the
editor remains a separate visibility option.

Area splits follow the actual campaign: Main Babe 10, New Babe Plus 9 and Ghost of
the Babe 8. Custom maps use their native Areas. Save PBs, best segments, run
history, notes and comparisons. Practice/continued runs remain separate from
eligible records. Replays integration supports linked recordings and ghosts.

Includes multiple layouts, map/aspect profiles, templates, Undo/Redo, anchors,
alignment, configurable buttons, text variables, images, charge and statistics.
Move the native timer and supported external providers, including Jump% with
Subframe Charge. Other mods can use the included provider API.

Requires JK Runtime 1.30+. Keep one active copy of the mod. Layouts and run history are
stored in Content/OverlayPlus, separately from Workshop updates. This is a local
record tracker; it does not validate leaderboard submissions.
