# Jetpack audio

`jetpack-loop-8bit.wav` is derived from
[Jetpack Loop](https://freesound.org/people/jacksonacademyashmore/sounds/402816/)
by jacksonacademyashmore, released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The source was converted to mono 11,025 Hz unsigned 8-bit PCM and prepared as a
seamless loop. The WAV is embedded in `MoreItems.dll` during the build.
