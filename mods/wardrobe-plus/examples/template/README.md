# Minimal skin template

Copy this directory, choose a unique manifest ID/name, and supply `my-skin.png`
at the source root using the game's complete atlas geometry. Native layout can
be exported with SkinTool. Validate and build it with the authoring tool described
in `docs/advanced-skins.md`. The template reuses native jump particles and does
not contain copied game art. Add PNG clips/WAV effects under `wardrobe/` as needed.
