# Count jumps in this attempt

This folder is an MME lesson to add to a working native map. It isn't a complete Jump King level.

1. Make a separate copy of your editable map for the lessons.
2. Copy this folder's `mapping_settings.xml` and, when present, `mme-assets` into that map's root, beside `level_settings.xml`. Replace the previous lesson's entry file; keep the native files.
3. Build and launch the map using [the loading steps](../../../docs/getting-started/worldsmith.md).
4. Go to screen 1 and try the lesson.

Expected result: Jumps: 0 appears at the top; each native jump adds one.

Read the [lesson sequence](../../../docs/getting-started/lessons.md) for the explanation, things to change and checks. Use a separate test map/save for lesson 7; its `saveId` is shared only by these lessons.
