# MME lessons

Read [setup](../../docs/getting-started/README.md) and [the lesson sequence](../../docs/getting-started/lessons.md). These are small additions to an existing playable native map, not complete standalone levels.

| Lesson | What it adds |
|---|---|
| [01: Image](01-image/README.md) | One PNG at a known position |
| [02: Placement](02-placement/README.md) | Position, scale and layer |
| [03: Animation](03-animation/README.md) | Ten-cell atlas playback |
| [04: Area caption](04-area-caption/README.md) | Sensor and visibility binding |
| [05: Counter](05-jump-counter/README.md) | Jump event, variable and text |
| [06: Sound](06-jump-sound/README.md) | One prepared WAV and a jump action |
| [07: Saved counter](07-saved-counter/README.md) | Save scope and a stable save ID |

Each folder contains its own required assets. Replace the previous lesson's entry file when copying a lesson. Keep the rest of your native map.
