# Mega Mapping Expansion documentation

Start with the [authoring handbook](authoring.md) to build one complete scene.
Use the [small recipes](recipes.md) when you need a focused example and the
[parameter reference](parameter-reference.md) when you already know which
element you are configuring. The standalone authoring kit includes the same
guide layout.

If you work in the native editor, read [Worldsmith authoring](worldsmith.md) for
its limits and for the portable extension, build and publish workflow.

## Guides

- [Architecture](architecture.md) explains loading, ownership and rendering.
- [Behavior trees](behavior-trees.md) and [scene effects](behaviors.md) cover
  dynamic scene logic.
- [Custom endings](endings.md) covers ending-specific behavior trees.
- [Large maps](large-maps.md) covers map sizes beyond the native assumptions.
- [Map policies](map-policies.md) lists requirements and restrictions.
- [Narrative](narrative.md) covers text, native actors and results.
- [Native workflows](native-workflows.md) explains how scene data fits existing
  map tools.
- [Reusable objects](objects.md) covers shared definitions and instances.
- [Scene API 1.0](scene-api.md) documents integration exposed to other mods.
- [Schema maintenance](schema.md) explains how the format and docs stay aligned.
- [Texture animation](texture-animation.md) covers frame-based image animation.
- [Preview and troubleshooting](troubleshooting.md) gives the short edit/reload
  loop and common failure checks.
