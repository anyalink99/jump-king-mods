# Mega Mapping authoring kit

Start with the [documentation index](../docs/index.md) and
[first-scene guide](../docs/authoring.md). Technical guides remain under `docs/`,
with generated schema and field catalogs under `reference/`.

The `props/` directory contains the minimal scene. Copy it into an existing
playable map with Mega Mapping Expansion and JK Runtime installed. The
`narrative/`, `behaviors/` and `behavior-trees/` directories contain independent
examples; choose one rather than combining their map roots indiscriminately.
This kit does not contain a complete playable route.

The `sdk/` directory contains the scene API assembly, IDE documentation and
consumer examples. See the [scene API guide](../docs/scene-api.md) for ownership
and capability requirements. `preview.ps1` assists native preview workflows;
see [troubleshooting](../docs/troubleshooting.md).
